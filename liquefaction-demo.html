What is liquefaction?

Soil liquefaction occurs when saturated soil temporarily loses strength during earthquake shaking and behaves like a liquid. It is a major hazard in the Philippines, especially near river systems and reclaimed land. CAR sits on complex terrain — some low-lying valley floors carry significant risk.

Technologies used
GeoDjango
Main application framework with built-in GIS support for spatial queries and polygon management.
Backend framework
Leaflet.js
Lightweight JavaScript library for rendering interactive maps and overlaying GeoJSON polygon layers.
Map rendering
SpatiaLite
Spatial extension of SQLite used to store and query liquefaction polygon geometries.
Spatial database
GeoPy / Nominatim
Python geocoding library using OpenStreetMap's Nominatim to convert addresses into coordinates.
Geocoding
HazardHunterPH
PHIVOLCS/OCD external API that provides official liquefaction and seismic hazard assessments.
External data source
OpenStreetMap
Free tile provider used as the base map layer for all geographic rendering in the app.
Base map tiles
